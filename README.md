# keydo Playground

An interactive, browser-based configuration tester for [keydo](https://github.com/argenkiwi/keydo). It runs the exact keydo Rust configuration parser and state machine compiled to WebAssembly via `wasm-bindgen`, enabling you to test remappings, layers, overloads, and chording entirely client-side.

---

## Features

- **Exact Engine Fidelity**: Uses keydo's Rust parser and keyboard state machine compiled to WASM.
- **Live Configuration Parsing**: Debounced syntax validation and error reporting as you type.
- **Interactive Virtual Keyboard**: Click keys to simulate key-down/up events and test layer activations.
- **Active Layer Badges**: Real-time layer activation badges showing currently active keyboard layers.
- **Event Log Stream**: Color-coded output event log showing key actions emitted by the engine.
- **Preloaded Examples**: Instant loading of common configurations (Vim navigation, Home row mods, Chording, Dvorak layout).

## Prerequisites

Before building or launching the playground locally, ensure you have:

- **Node.js**: `v18.0.0` or later (`node --version`)
- **npm**: `v9.0.0` or later (`npm --version`)
- **Rust Toolchain**: 2024 edition (`rustc --version`)
- **WASM Target**: `wasm32-unknown-unknown` target installed:
  ```bash
  rustup target add wasm32-unknown-unknown
  ```
- **wasm-pack**: `v0.12.0` or later:
  ```bash
  cargo install wasm-pack
  ```

## Quick Start

### 1. Install Dependencies

Install the npm dependencies:

```bash
cd playground
npm install
```

### 2. Launch Development Server

Run the development command, which compiles the WebAssembly module and starts the Vite dev server:

```bash
npm run dev
```

Open your browser at `http://localhost:5173`.

---

## Available Scripts

From inside the `playground/` directory, you can run:

| Command | Description |
|---|---|
| `npm run dev` | Compiles WASM module and starts Vite dev server with hot module replacement |
| `npm run build:wasm` | Compiles `keydo-wasm` Rust crate to `src/wasm/` using `wasm-pack` |
| `npm run build` | Builds WASM module and generates production frontend bundle in `dist/` |
| `npm run preview` | Serves the production `dist/` build locally for testing |
