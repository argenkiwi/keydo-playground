The release workflow (.github/workflows/release.yml) runs on pushes to main that touch package.json. It reads the version with `jq -r .version`, checks whether a git tag `vX.Y.Z` already exists, and if not creates the tag and a GitHub Release (with auto-generated notes) via softprops/action-gh-release@v2. The tag-exists guard makes the workflow idempotent — re-pushing the same version is a no-op. Requires `permissions: contents: write` at the job level.
