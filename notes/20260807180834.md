keydo-wasm/Cargo.toml pins the keydo dependency to a specific git rev rather than a semver range. To update it: (1) get the latest main rev via `git ls-remote https://github.com/argenkiwi/keydo refs/heads/main`, (2) update the `rev` field in Cargo.toml, (3) run `cargo update -p keydo` inside keydo-wasm/ to regenerate Cargo.lock. The rev maps to a specific keydo semver (e.g. rev 9c072ee = keydo v0.3.3).
